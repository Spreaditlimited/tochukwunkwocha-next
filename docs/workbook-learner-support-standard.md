# Prompt to Profit™ Learner-Support Standard

This standard is permanent for all future software workbooks.

## Front-of-workbook learner toolkit

Every standalone workbook must include these pages before Chapter 1:

1. Learner Support Toolkit
2. Visual Glossary
3. Work Safely: Make a Backup
4. Something Went Wrong — What Should I Check?
5. My Error Log

The glossary must explain recurring terms in short, beginner-friendly language.
The troubleshooting page must give learners a fixed order for investigating a
problem. The error log must provide writing space for the expected result,
actual result, first error message, files involved, attempted fixes and final
solution.

## Backup reminder

Whenever a Save Your Files section tells the learner to replace an existing
complete file, the reminder titled `BACK UP BEFORE REPLACING FILES` must appear
before the replacement instructions.

The learner must copy the complete project folder, keep the backup outside the
working/deployment folder, name it using the current chapter and lesson, and
confirm that the files are present.

## Code-reading question

A major capability is a lesson that asks AI to create or update HTML, CSS or
JavaScript application files.

Every such lesson must contain one short `CODE-READING QUESTION` immediately
before `WHAT YOU LEARNED`.

Orientation lessons, manual Supabase setup, database policy exercises, audits,
deployment instructions and portfolio writing do not require an artificial
code-reading question when they did not create or update application code.

Questions must ask the learner to open a real file from the lesson, locate one
relevant HTML element, CSS selector or JavaScript function, and describe what
it does in their own words.

## Publication requirement

The shared workbook builder validates the toolkit, glossary, backup reminders
and code-reading questions before publication.
